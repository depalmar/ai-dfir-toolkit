# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its Code of
Conduct. By participating, contributors, maintainers, and other community
members agree to uphold its standards in all project spaces and in public
spaces when an individual is representing the project.

In short: be respectful, welcoming, and constructive. Harassment and other
exclusionary behavior are not tolerated. Maintainers are responsible for
clarifying standards and may remove or reject contributions, comments, and
contributors that do not align with this Code of Conduct.

## Reporting

Report unacceptable behavior to the project maintainer — contact details are on
the maintainer's GitHub profile. All reports will be reviewed and investigated
promptly and fairly, and the privacy and security of the reporter will be
respected.
