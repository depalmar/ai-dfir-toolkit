# Brand files

`sans-logo.svg`, `sans-logo-white.svg` and `sans-logo.png` are the standard SANS
Institute wordmark, in its blue (`#004F6E`) and in white for dark backgrounds.
SANS supports this project and cleared the standard logo for it in November
2026. A DFIR-specific SANS logo is in progress; when it is released, replace
these files and keep the names, because the README and the site build
(`artifacts/scripts/build_site.py`) read them by name.
